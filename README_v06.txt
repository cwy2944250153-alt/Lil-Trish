花蝶小径 · TauriTavern 适配 v0.9（基于用户 v0.8）

本扩展和同包「徐引翠_v29_TauriTavern适配_主题.json」配套。
只有该主题实际生效（或原名 v29）且窗口宽度≤768px 时，才显示花蝶。

字体：在展开的花蝶导航右下角点「字体」，选择你已有的「上图东观体」.ttf 文件。
字体数据会保存在当前设备 WebView 的 IndexedDB 中，重启自动尝试恢复；不上传云端。
字体本身不包含在扩展文件内。旧字体文件可按需自行选择。

注意：TauriTavern 应用的安装扩展功能只接受 Git URL，不接受 ZIP；
需要把 xyc-floral-nav 作为前端扩展放入 TauriTavern 数据目录，或并入完整 ST 数据迁移备份。
